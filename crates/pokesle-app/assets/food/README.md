# 食材アイコン

`tools/food-icons/make.py` で作成したものです。ファイル名は本家の画像名(`master.json` の `foods[].img`)に合わせています。
本家の食材画像はゲームの画像のため使っていません。

| ファイル | 元 | ライセンス |
|---|---|---|
| `pureoil.png` / `slowpoketail.png` / `moomoomilk.png` | このリポジトリで描いたもの | MIT(このリポジトリの [LICENSE](../../../../LICENSE)) |
| `fancyegg.png` | Noto Emoji 🥚 (U+1F95A) の色を白に変更 | OFL-1.1 |
| `greengrasssoybeans.png` | Noto Emoji 🫘 (U+1FAD8) の色をクリーム色に変更 | OFL-1.1 |
| 上記以外 | Noto Emoji をそのまま縮小 | OFL-1.1 |
